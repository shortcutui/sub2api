# 鹈鹕展示账号池

在「智能运维 → 鹈鹕测智」的测试计划旁点击「展示账号池」，可以为该展示分组配置：

- **自动调度**：沿用原行为，从整个分组中选择账号。
- **指定展示账号**：勾选该分组内的 1–100 个账号，仅允许这些账号生成展示作品。

账号池按分组保存，同组全部鹈鹕绘图计划共用，新增计划也会遵守。修改从下一轮开始生效；已开始的一轮使用开始时读取的名单。普通用户请求、账号级测试及渠道监测不受这份展示配置影响。

## 失败与账号失效

指定账号仍须满足原调度器的状态、并发、限流、模型和平台条件。请求发生原有可重试错误时，排除该账号，在池内重新调度；每份最多尝试 3 个不同账号。模型成功返回但画得不好，不触发质量判断或额外重试。

账号移出分组或删除后不会继续参与绘图；调度缓存选中账号后，还会在实际调用前重新检查分组成员关系。管理员重新打开配置时会看到失效选择，需要取消后才能保存指定模式。池内账号全部不可用、配置读取失败或名单全部失效时，本轮记录失败，不回退整个分组，也不发布新作品。既有作品仍按原张数和天数规则保留，生成时间不会改写。

后台继续记录实际作答账号、失败尝试、耗时和已知费用；用户展示页及只读作品 API 不提供账号池或账号身份信息。指定账号只限定作品来源，不代表整组账号的实时质量。

## 实现与合并上游

主体实现放在独立文件：

- `backend/internal/service/pelican_showcase_account_pool.go`：配置校验、每轮名单快照、候选过滤、调用前成员复核。
- `backend/internal/repository/pelican_showcase_account_pool_repo.go`：配置表读写和不包含凭据的账号摘要。
- `backend/internal/handler/admin/pelican_showcase_account_pool_handler.go`、`backend/internal/server/routes/pelican_showcase_account_pool.go`：管理员读写接口。
- `frontend/src/features/pelican-account-pool/`：独立按钮、弹窗、请求、中英文文案及交互测试。
- `backend/migrations/296_pelican_showcase_account_pools.sql`：独立配置表，无旧数据回填。

现有文件仅保留接入点：分组测试仓库 interface 和执行入口、通用网关候选过滤、管理员路由注册、管理页组件挂载，以及中英文语言入口的命名空间注册。OpenAI 复用现有测智模型候选过滤入口，继续走原调度器，不另建调度实现。

管理员接口为 `GET/PUT /api/v1/admin/pelican-showcase/groups/:id/account-pool`，PUT 请求示例：

```json
{"mode":"selected","account_ids":[11,12]}
```

恢复自动调度：

```json
{"mode":"automatic","account_ids":[]}
```

响应包含 `pool` 和当前分组的 `accounts` 摘要。指定模式不接受空名单、非正整数 ID 或其他分组账号；错误保存不覆盖旧名单。切回自动模式删除独立配置行。删除测试计划不会清除分组的账号池配置，删除分组则级联清除。

升级需要前后端一起更新，后端启动时应用新迁移。旧版本不会读取账号池表，回滚后会恢复全组调度；如需维持指定范围，应先暂停对应绘图计划。未来合并上游如遇迁移编号冲突，应在该迁移首次部署前调整编号；已经应用的迁移文件不应改名或改写。

## 验证

- 服务测试覆盖空名单、重复 ID、自动模式、配置读取失败、池内重试、池外防护、调用前移组复核，以及 OpenAI 两种调度器和 Messages 调度器。
- PostgreSQL 集成测试覆盖持久化、跨组 ID 拒绝、失效账号保留指定模式、恢复自动和迁移幂等。
- 前端测试覆盖多选、搜索后保留选择、失效 ID、加载和保存错误、同组配置读取及恢复自动。

测试只使用本地模拟响应和临时数据库，不调用真实模型。
